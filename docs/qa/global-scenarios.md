# Global Scenarios 1–15: Test Traceability (Q7.3)

Scenarios from [architecture doc 13 §11](../architecture/13-global-marketplace.md). Each one is covered by at least one automated test; the ones that had no end-to-end feature test were added in Q7.3 (`tests/Feature/Global/GlobalScenariosTest.php`, marked **new**). All tests pass on SQLite and MariaDB.

## Notes

- Scenario 1 compares the visible text: the amount and the currency symbol are separate elements in the card markup, so raw-HTML matching is not enough.
- Scenario 10: the ad page of a deactivated country answers **404** (the scenario allows 404 or 410; 410 is used for deleted and expired ads).
